01 / About

Get to know a performance-focused distro.

CachyOS is a community-developed, Arch-based Linux distribution. Its goal is to deliver a fast, approachable desktop experience without sacrificing Arch's flexibility or rolling-release model.

What makes it different?

The project combines package builds for modern CPUs, tuned Linux kernels, and configuration tools to make the system more ready to use.

  • ✳Repositories provide package variants for targets such as x86-64-v3, x86-64-v4, and Zen 4; actual support depends on your processor.
  • ✳The linux-cachyos kernel offers configurable schedulers and multiple variants.
  • ✳Graphical and CLI installers offer different levels of control during setup.

Flexible like Arch

CachyOS remains part of the Arch rolling-release ecosystem. Updates arrive continuously, so read announcements and follow the official guidance before making major changes.

03 / Why CachyOS

Performance comes from many layers.

Optimization isn't magic—real-world results vary based on hardware, workload, and configuration.

↗

Optimized packages

CachyOS repositories provide builds for modern CPU targets. Select core packages also use additional optimization techniques such as PGO and BOLT.

⌁

Kernel choices

The linux-cachyos kernel is developed with tuning and multiple variants. Choose a kernel to suit your needs; no single option is right for everyone.

▤

Tools & tweaks

The project ecosystem includes CachyOS-Settings and Ananicy Cpp for system configuration and resource prioritization on supported setups.

▧

Desktop choices

Choose a desktop environment that fits your workflow during installation. Options include KDE Plasma, GNOME, COSMIC, Hyprland, Sway, Niri, i3, XFCE, and more.

Rolling release

The system is updated continuously rather than through periodic major version upgrades. Check official announcements and upgrade guidance.

Community project

CachyOS is an independent, community-supported project. Its documentation and forums help users learn and troubleshoot.

04 / Get started

Get ready to install.

Always use installation guides and images from official CachyOS channels. Back up important data first.

OPTION A — GUI

Graphical installer

Calamares provides a guided visual installation flow. It’s a good fit for users who prefer a visual setup experience.

OPTION B — CLI

Terminal installer

The CLI option offers more control through a text-based flow. It’s suited to users who are comfortable reviewing configuration choices.

Before installing: review the requirements and partitioning guide in the Wiki, verify the image using the release instructions, and understand that installation may modify or erase data on the selected disk.
